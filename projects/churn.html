MACHINE LEARNING PROJECT

Customer Churn Prediction

A machine-learning classification project focused on predicting customer churn through data preparation, exploratory analysis, model comparison, hyperparameter tuning, and Streamlit deployment.

View on GitHub → ← Back to Projects

OVERVIEW

Project Overview

Customer churn occurs when customers stop using a company's products or services. This project explores how machine learning can be used to identify customers who may be at risk of leaving.

I worked through the complete machine-learning workflow, including data inspection, data preparation, exploratory analysis, model training, evaluation, hyperparameter tuning, and deployment.

Dataset 1,000 records
Features 10 columns
Problem Type Classification
Deployment Streamlit

OBJECTIVE

What I Set Out to Do

The main objective was to develop a classification workflow capable of predicting whether a customer would churn based on available customer information.

  • Inspect and understand the dataset
  • Identify and address data-quality issues
  • Explore relationships within the data
  • Train multiple classification algorithms
  • Compare model performance
  • Tune selected models using GridSearchCV
  • Deploy a trained model using Streamlit

DATA PREPARATION

Preparing the Data

Before training the models, I inspected the dataset to understand its structure and identify potential data quality issues.

MODEL TUNING

Hyperparameter Optimization

GridSearchCV was used to search through combinations of hyperparameters for selected models rather than manually choosing the final values.

Tuned Decision Tree

  • Criterion: Entropy
  • Maximum depth: 30
  • Minimum samples per leaf: 4
  • Minimum samples to split: 5
  • Splitter: Random

These values were selected by GridSearchCV based on the parameter combinations evaluated during tuning.

DEPLOYMENT

Streamlit Application

The project includes a Streamlit application that provides an interface for interacting with the trained machine-learning model.

The model saved for deployment was the tuned Decision Tree selected during the model-tuning workflow.

LEARNING OUTCOMES

What I Learned

  • How to inspect and prepare a real dataset for machine-learning workflows.

  • The importance of separating model performance evaluation from deployment decisions.
